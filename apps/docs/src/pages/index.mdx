# Vektorprogrammet migration

Use this site to understand migration state, operate one capability cutover, and find exact source or evidence.

:::warning
The public application at `vektor.phibkro.org` is a development preview. Its database contains synthetic data. It is not production.
:::

## Routes & API

:::info
Open [Routes & API](/reference/routes-and-api) for route families, capability ownership, native and legacy boundaries, and current API availability.
:::

## Current posture

- The legacy Symfony application and MySQL remain the production authority at the inspected revision.
- Native TypeScript capabilities run through Effect Services, Layers, PostgreSQL, and a separate backend.
- The development preview records selected native page and session observations.
- The repository does not prove final functional parity or a production cutover.
- The inspected revision has no checked-in `STATE.md`.

Read the [migration state](/reference/migration-state) for capability details. The [preview evidence](https://github.com/vektorprogrammet/mono-web/blob/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/evidence/0069-apex-preview-deployment.json) records the synthetic-data and `dev-main` boundaries.

## Evidence rule

A source file proves that code exists. A test records behavior for its cases. A preview record reports one runtime observation.

None of these items proves production cutover unless a specific artifact records that authority change.
