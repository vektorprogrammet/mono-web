# Routes & API

[`NativeApi`](https://github.com/vektorprogrammet/mono-web/blob/c315db3b5809caffb16e149bd33f0a07b60948f6/packages/http-api/src/api.ts) is the native HTTP contract authority. [`makeBackendHttp`](https://github.com/vektorprogrammet/mono-web/blob/c315db3b5809caffb16e149bd33f0a07b60948f6/apps/backend/src/router.ts) keeps Better Auth as the only external path family.

## Current API availability

The native backend serves the route families below. Open the [generated native API reference](/reference/native-api) for all 47 public operations, schemas, and responses.

The public document excludes Better Auth and the internal receipt evidence route. The operation total does not claim legacy capability parity.

## Boundary rules

1. `NativeApi` selects one typed endpoint contract.
2. The matching `HttpApiBuilder` handler decodes transport input.
3. The handler resolves one actor and one authorization instant when the capability needs them.
4. The handler calls a Service program.
5. The handler maps typed outcomes to HTTP.
6. The handler does not select a live persistence implementation.

Unknown native paths return `404` with `RouteNotFound`.

## Browser route boundary

React Router owns URL matching and server loaders. A Foldkit route bridge mounts a finite browser program.

Source areas:

- [`apps/dashboard/app/routes.ts`](https://github.com/vektorprogrammet/mono-web/blob/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/routes.ts)
- [`apps/dashboard/app/routes`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/routes)
- [`apps/dashboard/app/foldkit`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/foldkit)

The route bridge can pass decoded input and forward messages. It must not duplicate the Foldkit `Model` or backend write state.

## Legacy API boundary

Legacy API Platform resources remain under [`apps/server/src/App`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/server/src/App).

Use the parity inventory to compare declared legacy and native routes. Do not treat similar path text as behavioral parity.
