# Routes and API boundaries

[`makeBackendHttp`](https://github.com/vektorprogrammet/mono-web/blob/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/backend/src/router.ts) is the native HTTP dispatch authority.

## Native route families

| Route family                                                                                                                                                                                   | Adapter                        | Capability owner                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ----------------------------------------------- |
| `/api/auth/*`                                                                                                                                                                                  | Better Auth request handler    | Shared `AuthEngine` and `Identity` Layer        |
| `/api/me/session`                                                                                                                                                                              | Router session projection      | `Identity`                                      |
| `/api/me`                                                                                                                                                                                      | `makeProfileApiHttp`           | `Profile`                                       |
| `/api/receipts*`, `/api/admin/receipts*`                                                                                                                                                       | `makeReceiptApiHttp`           | `Economy`                                       |
| `/api/applications*`, `/api/admission-periods/open`, `/api/admin/admission-periods*`                                                                                                           | `makeAdmissionApiHttp`         | `Admissions` and application domain programs    |
| `/api/admin/recruitment*`, `/api/recruitment/invitation-response*`                                                                                                                             | `makeRecruitmentApiHttp`       | `Recruitment`                                   |
| `/api/departments`, `/api/teams`, `/api/field_of_studies`, `/api/admin/departments`, `/api/admin/teams`, `/api/admin/field-of-studies`, `/api/admin/team-interest`, `/api/admin/mailing-lists` | `makeOrganizationApiHttp`      | `Organization`                                  |
| `GET /api/admin/schools`                                                                                                                                                                       | `makeSchoolsApiHttp`           | `Schools`                                       |
| `/api/admin/content*`                                                                                                                                                                          | `makeContentManagementApiHttp` | `ContentManagement`                             |
| `/api/news*`                                                                                                                                                                                   | `makePublicNewsApiHttp`        | `Content`                                       |
| `GET /api/admin/users`                                                                                                                                                                         | `makeAdminUsersApiHttp`        | Identity, profile, and organization projections |
| `GET /health`                                                                                                                                                                                  | Router health adapter          | `Database`                                      |

The exact path predicates are at the top of [`apps/backend/src/router.ts`](https://github.com/vektorprogrammet/mono-web/blob/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/backend/src/router.ts).

## Boundary rules

1. The router selects one adapter for each path family.
2. The adapter decodes transport input.
3. The adapter resolves one actor and one authorization instant when the capability needs them.
4. The adapter calls a Service program.
5. The adapter maps typed outcomes to HTTP.
6. The adapter does not select a live persistence implementation.

Unknown native paths return `404` with `RouteNotFound`.

## Browser route boundary

React Router owns URL matching and server loaders. A Foldkit route bridge mounts a finite browser program.

Source areas:

- [`apps/dashboard/app/routes.ts`](https://github.com/vektorprogrammet/mono-web/blob/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/routes.ts)
- [`apps/dashboard/app/routes`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/routes)
- [`apps/dashboard/app/foldkit`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/dashboard/app/foldkit)

The route bridge can pass decoded input and forward messages. It must not duplicate the Foldkit `Model` or backend write state.

## Legacy API boundary

Legacy API Platform resources remain under [`apps/server/src/App`](https://github.com/vektorprogrammet/mono-web/tree/0bc4aa3ac5506b6371d25972c9608eee8e35c17d/apps/server/src/App).

Use the parity inventory to compare declared legacy and native routes. Do not treat similar path text as behavioral parity.
