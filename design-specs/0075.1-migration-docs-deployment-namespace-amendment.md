The operator supplied the existing Alchemy profile label. The label selects stored authority without exposing credential values.

This amendment replaces the `docs-main` stage in design spec 0075 with `docs-dev-main`.

The dedicated stack and stage create this state namespace:

```text
.alchemy/state/vektor-docs/docs-dev-main
```

This namespace must not overlap the apex preview namespace:

```text
.alchemy/state/vektor/dev-main
```

Before deploy, the operator must inspect sanitized `alchemy state list` metadata or the equivalent plan output. The inspection must show no ownership collision.

The plan and deployment can change only the docs Worker, its static assets, and `vektor-docs.phibkro.org`.

The deployment must not change the apex or API aliases. It must not change any preview Worker or existing state record.

All other requirements in design spec 0075 remain frozen.
