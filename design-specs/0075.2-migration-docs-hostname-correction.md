## Correct identity

This amendment replaces each docs deployment identity from the earlier specs.

| Field | Correct value |
| --- | --- |
| Public URL | `https://vector-docs.phibkro.org` |
| Hostname | `vector-docs.phibkro.org` |
| Stack | `vector-docs` |
| Stage | `docs-dev-main` |
| Worker | `vector-migration-docs` |
| Logical resource | `VectorMigrationDocs` |
| Local state | `.alchemy/state/vector-docs/docs-dev-main` |

The Vocs `baseUrl`, generated schema URLs, deployment guide, tests, and machine-readable state must use this identity.

## Wrong deployment correction

The wrong docs-owned deployment used `vektor-docs.phibkro.org` and `vektor-migration-docs`.

Use this order:

1. Plan the correct `vector-docs` stack.
2. Deploy the correct Worker and hostname.
3. Verify TLS, pages, assets, search, browser behavior, and machine-readable output.
4. Plan deletion of only the wrong `vektor-migration-docs` Worker and its custom domain.
5. Delete the wrong docs-owned resource.
6. Verify that the wrong hostname is no longer live.
7. Record creation and deletion effects in sanitized evidence.

Do not delete the wrong resource before the correct hostname passes the live checks.

## Authority boundary

This correction can change only the two docs-owned deployments during the handover.

It must not change:

- `vektor.phibkro.org`
- `api.vektor.phibkro.org`
- `vektorprogrammet.no`
- an application Worker
- an existing preview resource
- production data
- a credential or profile record

The final state contains only the correct docs Worker and custom domain. The old docs state can remain as an empty local historical record.

## Evidence

The evidence must record:

- the wrong hostname and Worker that were created
- the correct hostname and Worker that became live
- the plan for the correct creation
- the plan for the wrong-resource deletion
- the result of both provider changes
- live checks for the correct site
- the final response from the wrong hostname
- source revision and artifact digests

Evidence must not contain credential values, profile labels, account IDs, cookies, or absolute operator paths.
