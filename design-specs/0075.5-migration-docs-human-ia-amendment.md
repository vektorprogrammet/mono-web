## Information architecture

`Routes & API` is a primary top navigation item. It links to `/reference/routes-and-api`.

The Reference sidebar puts this page near the start. The home page has a prominent section with a direct link. The section states that the page contains route families, capability ownership, native and legacy boundaries, and current API availability.

Human keyword search remains enabled.

## Human-first controls

Every documentation page sets the Vocs `showAskAi` frontmatter value to `false`. Vocs 2.8.5 does not expose this value as a site-level configuration field. Applying the page value to every page removes both the Ask AI control and the copy-for-AI control from the complete site.

Set `mcp: { enabled: false }` in the Vocs configuration. Vocs 2.8.5 supports this exact field.

Do not advertise agents, MCP, `llms.txt`, copy-for-AI, or machine-readable output in the home page, navigation, product description, or acceptance criteria. Vocs can continue to generate its internal text outputs because version 2.8.5 has no supported disable switch.

Keep `migration-state.json` as the source-backed projection for human migration-state pages. Do not present the file as a headline product feature.

## API reference boundary

Do not add a handwritten OpenAPI document, a placeholder API reference, or a page that implies a generated running contract.

A generated API reference can follow only after the separate 0077 work provides a running Effect HttpApi contract.
