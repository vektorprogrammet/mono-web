## Amendment

Use `@effect/docgen@4.0.0-rc.109` for generated code reference pages.
This version matches the repository `effect@4.0.0-rc.109` release.

The published docgen peer range accepts TypeScript versions from 5.8.2 through versions before 7.
The repository keeps `typescript@7.0.2` as its direct application checker.
This work must not downgrade, replace, or weaken that checker.

Add a narrow docs-tool dependency named `typescript-docgen`.
Pin the alias to `npm:typescript@6.0.2`.
Point the docgen `tscExecutable` configuration at the alias binary.
Do not state that docgen supports TypeScript 7.

Run the installed CLI against the selected source files.
Record its actual success or exact failure.
If the runtime fails despite the supported compiler alias, inspect only its official published programmatic API.
Use that API only when it produces behavior equivalent to the official CLI.
Do not replace docgen with a hand-written parser or printer.

All other requirements in design spec 0079 remain unchanged.
